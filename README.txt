圣诞树动画｜使用说明

1. 直接双击 index.html 打开动画，不需要安装软件，也不依赖其他脚本文件。
2. 右侧输入框可以修改两行祝福，可暂停、调速、重新开始。
3. 点击“保存我的网页”保留你的祝福；保存的 HTML 可以独立离线打开。
4. christmas.mp4 是默认祝福的 20 秒竖屏无声成片，1080×1920，30 fps。网页改字不会自动修改 MP4。
5. 想改造型：用记事本打开 index.html，搜索 scene-engine；scene.js 是同一场景的独立源码，可用于重新导出视频；hues 是色彩，gifts 是礼物尺寸位置，draw 中包含默认祝福与布局。
6. christmas-web.zip 内含可离线使用的网页源码。视频单独下载，放在网页同目录即可在页面中播放。

公开内容仅限本动画网页、场景代码、成片、封面、源码包和本说明；不包含参考视频和 MIAO 其他文件。
